# Analysis — Valis case (Northwind-in-a-box)

All outputs for the exercise. Source data stays untouched in the repo root. Python 3.9+, standard library only, no install step.

## Run everything (≈1 second)
```bash
python Analysis/ask.py --all                       # 1. answers both CEO questions -> output/answers.md
python Analysis/automation/taxform_chaser.py       # 3. the shipped automation     -> output/taxform/
python Analysis/automation/support_autopilot.py    #    broader support version    -> output/autopilot/
python Analysis/value_number.py                    # 2. CFO worksheet              -> VALUE_NUMBER.md
python -m unittest discover -s Analysis/tests -v   # acceptance tests (24)
```
Ask anything: `python Analysis/ask.py "Are we still hiring AEs?"`. If no answerer fits, it says so instead of guessing. Run on a different copy of the data: `--data DIR` (ask) or `--tickets FILE` (autopilot).

## Decision
**Tax-form chasing (W-9 / W-8) is the workflow that will be automated** — selected and confirmed 2026-10-28, after local testing. Cadence: e-sign request, reminders on day 3 and 7, hand-off to a person on day 14. **Everything for it is in one folder: [`taxform_automation/`](taxform_automation/)** (spec, walkthrough, decision record, links to code and outputs).

All decisions (D1 automation, D2 value number): [`DECISIONS.md`](DECISIONS.md).
