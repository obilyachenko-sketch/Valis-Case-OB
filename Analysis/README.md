# Analysis — Valis case (Northwind-in-a-box)

All outputs for the exercise. Source data stays untouched in the repo root. Python 3.9+, standard library only, no install step.

## Run everything (≈1 second)
```bash
python Analysis/ask.py --all                       # 1. answers both CEO questions -> output/answers.md
python Analysis/automation/support_autopilot.py    # 3. runs the automation       -> output/autopilot/
python Analysis/value_number.py                    # 2. CFO worksheet              -> VALUE_NUMBER.md
python -m unittest discover -s Analysis/tests -v   # acceptance tests (13)
```
Ask anything: `python Analysis/ask.py "Are we still hiring AEs?"`. If no answerer fits, it says so instead of guessing. Run on a different copy of the data: `--data DIR` (ask) or `--tickets FILE` (autopilot).
